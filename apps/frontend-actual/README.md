# Frontend actual (legacy)

El código fuente vive en [`escribanos/frontend`](../../escribanos/frontend) durante la migración gradual.

- **Puerto dev:** `3000`
- **API:** proxy `/nest-api` → backend unificado (`localhost:4000/api/v1`)

Comandos desde la raíz:

```bash
npm run dev:frontend-actual
# equivalente a npm run dev -w escribanos-frontend
```

Cuando la migración termine, el contenido se moverá aquí de forma definitiva.
